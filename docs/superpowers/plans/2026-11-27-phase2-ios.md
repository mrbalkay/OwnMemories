# OwnMemories Aşama 2 — Tailscale + iOS Yedekleme Uygulama Planı

Hazırlayan: Mehmet BALKAY

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Tailscale HTTPS erişimi ve arka planda yedekleme yapan iOS uygulamasının TestFlight'a gönderilmesi.
**Architecture:** Sunucuya cihaz bildirimi ve yükleme bağlantı meta verisi eklenir. iOS: SwiftUI uygulaması +
platformdan bağımsız `OwnMemoriesCore` Swift paketi (modeller, plan mantığı; `swift test`). Derleme ve imza
GitHub Actions (macOS) üzerinde.
**Tech Stack:** PHP 8.1+, MySQL; Swift 5.9+, SwiftUI, SwiftData, PhotoKit, BackgroundTasks, URLSession (background), XcodeGen.
**Spec:** `docs/superpowers/specs/2026-11-27-phase2-ios-tailscale-design.md`

## Global Constraints
- iOS 17.0+, yalnız iPhone, bundle `net.balkay.ownmemories`, BG görev kimlikleri `net.balkay.ownmemories.refresh` ve `.backup`, arka plan URLSession kimliği `net.balkay.ownmemories.upload`.
- Parça boyutu sunucudan (`chunk_size`, 50 MB) okunur.
- `source_ref` biçimi: `<localIdentifier>`, `<localIdentifier>#live`, `<localIdentifier>#edited`.
- Token Keychain'de; sunucu adresi UserDefaults'ta. Arayüz metinleri Türkçe.
- Sunucu SQL'i MySQL 5.7 uyumlu; yeni tablolar migrasyonla (003) ve schema.sql'de.

## Review Focus
1. Tailscale kapalı / sunucuya ulaşılamıyor → yedekleme hata vermeden bekler, durum ekranı açıklar.
2. Uygulama yükleme ortasında öldürülür → arka plan oturumu parçayı bitirir; sonraki açılışta `GET uploads/{id}` ile kaldığı yerden devam.
3. iCloud'da optimize edilmiş (cihazda olmayan) fotoğraf → ağdan indirilip yüklenir; indirme başarısızsa öğe hata ile işaretlenir, sonra yeniden denenir.
4. Aynı fotoğraf Takeout ile zaten sunucuda → `assets/check` "var" der, yüklenmez, `done` sayılır.
5. Çok büyük video (> 4 GB) → bellek yerine dosyadan parça parça okunur.
